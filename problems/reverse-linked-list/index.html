Problem

Given the head of a singly linked list, reverse the list, and return the reversed list.

Constraints

  • —The number of nodes in the list is in the range [0, 5000].
  • —-5000 <= Node.val <= 5000

Follow-up: A linked list can be reversed either iteratively or recursively. Could you implement both?

Solution

2 approaches · Python and Go. Pick a tab — the walkthrough follows.

Optimal▶ Animated

Walk the list once, flipping each arrow to point backwards. O(1) extra space.

Keep prev (head of the reversed part), curr (node being processed) and nxt (a lifeline to the unprocessed part). Save, flip, advance, repeat.

Algorithm

  1. prev = None, curr = head.
  2. While curr: save nxt = curr.next.
  3. Flip: curr.next = prev.
  4. Advance: prev = curr, curr = nxt.
  5. Return prev.
Time
O(n)
Space
O(1)
