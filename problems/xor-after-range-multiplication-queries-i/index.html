XOR After Range Multiplication Queries I — binary search

Halve the sorted range until the target is found or the range collapses. Built for LeetCode 3653. XOR After Range Multiplication Queries I.

Because the slice is sorted, comparing nums[mid] to target tells you which half can be thrown away. That is the whole algorithm.

Algorithm

  1. While lo <= hi, pick mid.
  2. Equal → return mid. Too small → search right. Too big → search left.
  3. Empty range → not found (-1).
Time
O(log n)
